# RILL artwork prompts

The icon and concept lockup were created with the built-in imagegen tool. Original generated files are preserved as `rill-icon-source.png` and `logo-concept.png`. Platform icon sizes are mechanically downscaled from the original; ICO/ICNS only package those pixels. The production SVG wordmarks use actual outlined Inter SemiBold glyphs, and the app uses the same bundled font as live text for crisp theme-adaptive lettering.

## Icon

Use case: logo-brand.
Asset type: production desktop application icon for RILL, a focused professional digital audio workstation.
Create ONE finished app icon, centered on a 1024x1024 transparent canvas. An elegant rounded-square charcoal tile occupies about 88% of the canvas with generous transparent outer padding. Within it, a bold, distinctive sea-glass teal R monogram is constructed from a continuous, flowing ribbon with a subtle parallel channel/negative-space cut: evoke a small flowing stream and an audio signal, while remaining unmistakably readable as an R. Strong simple silhouette, generous inner negative space, carefully balanced proportions, clean geometric curves, crisp edges. Upper bowl and diagonal leg must read clearly at 32 pixels.
Style: minimalist premium music software identity, mostly flat with a very gentle broad radial tint across the teal and subtle depth in the charcoal tile. Existing UI colors: charcoal #1B1F21 and muted teal #78B9AC; use these as anchors with a light sea-glass highlight for clarity. Calm, confident, timeless, not flashy. The tile can have a restrained soft shadow entirely inside the canvas.
No lettering other than the R symbol. No full word, no headphones, musical note, equalizer bars, play triangle, knobs, circuitry, glossy plastic, chrome, 3D extrusion, sparkles, background scene, mockup, presentation board, border text or watermark. Single centered icon only. Actual alpha transparency outside the rounded tile; do not draw a checkerboard.

## Concept logo

Use case: logo-brand.
Asset type: horizontal RILL logo, transparent PNG brand asset for professional audio workstation software.
Input image is the reference for the finished app icon and its exact R monogram. Create one clean horizontal logo lockup: the same charcoal rounded-square icon with sea-glass teal flowing R, then the exact word "RILL" in uppercase on its right. Preserve the identity and geometry of the reference mark; do not invent a second symbol. The wordmark uses a refined geometric/grotesk sans serif similar to Inter SemiBold, clean straight stems, an open clear R, subtly generous letter spacing and carefully optical spacing. Letter color charcoal #1B1F21. The text must read precisely R I L L, no tagline or additional words.
Composition: wide horizontal canvas around 3:1, balanced centered lockup, icon vertically aligned with wordmark, comfortable space between icon and lettering, 10% transparent padding around overall logo. The icon is slightly taller than the capital letters. The icon keeps its gentle teal tint and charcoal tile; lettering is entirely flat, crisp and sober. Transparent background, no checkerboard, no scene, no presentation board, no effects on the lettering. This version is intended for light backgrounds. One logo only.
