Participant 4 — simulated beginner, casual video creator, goal: roughly 30-second ambient soundtrack.
Initial reaction: Arranger opens with an 8.571-second Circuit rhythm audio clip. Large transport buttons and the blank-area hint for MIDI are clear. I will try the explicit double-click hint.
The blank-area double-click opened the instrument library and Assign instrument created a track and empty pattern. Double-clicking the pattern appeared to do nothing; right-click exposed Edit notes, which is understandable. The library clearly labels the supplied instrument as VST3.
I drew three notes using Pencil with Length: 1 bar, then dragged their right edges toward four bars. Properties displayed precise elapsed time. The notes ended at slightly different locations despite aiming at the same screen column; I need to inspect the snap behavior. Pleasant surprise: the Name property has a visible Keyboard button, allowing mouse-only naming. I named the first MIDI pattern Dusk.
Dragging the MIDI clip edge to match the audio endpoint and using Duplicate created contiguous four-bar sections. Fit made the full 34.286 seconds visible, with a helpful 30.00-second ruler label for trimming. Zoom buttons and real-time labels are useful for a video-length target.
Repeated audio and MIDI both cover about 30 seconds. I lowered the drum track to -30 dB to keep the sustained instrument prominent. Turning Loop off and pressing Play displayed Preparing audio before playback. I am not hearing audio in this screenshot-based session, so the intended ambient result is not an auditory quality judgment. Trimming near the 30-second ruler mark left total length 30.402 seconds, which is close but not exact.
After playback, a banner reported Plug-in/render error: 3119 failures and advised Stop and restart playback to retry. This interrupts confidence that the instrument is working. I stopped and opened Details. File > Rename project also provides a mouse keyboard, so I renamed the project DUSK.
Save used the project name as the suggested filename DUSK.rill and opened directly in my session directory; one mouse click accepted it. I then selected 1 bar snap to improve endpoint precision, reaching 30.134 seconds, and varied upper notes in the middle two MIDI sections. Previous/Next in the clip editor made moving between sections convenient. File exposes both requested export formats clearly.
WAV export defaulted to 48 kHz, stereo, 32-bit float with an Include effect tails checkbox. I unchecked tails to keep the cue near the video target. The GTK save dialog suggested DUSK.wav in the same session directory. Export then showed elapsed seconds in a bottom status bar. The project and export naming defaults avoid typing in the native dialog.
Final: The UI reported Exported · DUSK.wav and then Exported · DUSK.mid. The arrangement title reads DUSK and 0:30.134. Both audio and MIDI clips are visible. I completed the requested save and both export commands using only mouse input, but cannot validate audible VST output because I did not audition a capture and earlier playback reported thousands of plug-in/render failures. I would need confidence in that error before using the cue in a video. The app looks clean and the core workflow was discoverable after a few context-menu attempts.
